## [1.0.0] - 2026-08-26

### Added

- Reproducible one-script installation for GNOME Shell 46–50.
- Pinned Dash to Dock 105, Blur My Shell 72, Flourish 1.0.0, and Just
  Perfection 36 sources with SHA-256 verification.
- Primary-only favorites, Trash, removable media, and intellihide behavior.
- Per-monitor running-application filtering on secondary docks.
- Blur My Shell startup-race repair for all monitor docks.
- Neutral dark 40 px floating dock preset with dynamic blur and hover motion.
- Pinned WhiteSur installation with custom VK, eXpress, and Codex SVGs.
- Automatic backup, rollback, explicit restore, dry-run, and status checks.
- English and Russian documentation plus complete community and security files.
