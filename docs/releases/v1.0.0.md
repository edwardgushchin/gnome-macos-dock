# GNOME macOS Dock 1.0.0

The first public release captures the complete reference dock and WhiteSur
integration as a reproducible, reversible user installation.

## Included

- pinned and checksum-verified GNOME extensions;
- primary-only favorites, Trash, removable media, and intellihide;
- monitor-local running applications on secondary docks;
- reliable dynamic blur across all monitor docks;
- 40 px icons, neutral dark translucent material, and a floating bottom gap;
- Flourish hover magnification and a single short launch bounce;
- pinned WhiteSur with custom VK, eXpress, and Codex Desktop SVGs;
- complete dconf presets, automatic backup and rollback, restore, status, and
  isolated integration tests;
- English and Russian documentation, community templates, and security policy.

## Compatibility

GNOME Shell 46–50. The reference and visual acceptance environment is GNOME
Shell 50.4 on Wayland with three monitors.

## Install

```bash
git clone --branch v1.0.0 --depth 1 \
  https://github.com/edwardgushchin/gnome-macos-dock.git
cd gnome-macos-dock
./install.sh
```

Review [SECURITY.md](../../SECURITY.md) and
[THIRD_PARTY.md](../../THIRD_PARTY.md) before installation.
