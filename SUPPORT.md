# Support

Choose the channel that matches the request:

- Read the [settings reference](docs/SETTINGS.md),
  [compatibility guide](docs/COMPATIBILITY.md), and
  [troubleshooting guide](docs/TROUBLESHOOTING.md).
- Start a [GitHub Discussion](https://github.com/edwardgushchin/gnome-macos-dock/discussions)
  for installation help, customization ideas, screenshots, and general
  questions.
- Open an [issue](https://github.com/edwardgushchin/gnome-macos-dock/issues/new/choose)
  for a reproducible defect or concrete feature request.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Never put
  sensitive details in a public issue.

When asking for help, include:

- the project release or commit;
- distribution and GNOME Shell version;
- Wayland or X11;
- monitor count, layout, and primary display;
- output from `./status.sh`;
- the smallest useful redacted log excerpt.

Never upload a backup directory, dconf database, private desktop launcher, or
full home-directory path. Support is provided on a best-effort basis.
